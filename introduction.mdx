## Quick Integration

<Steps>
  ### Get API Access
  Sign up at [dashboard.palm.io](https://dashboard.palm.io/signup) and obtain your API keys

  ### Choose Your Integration
  ```bash
  # Direct API Access
  curl -X GET "https://api.palm.com/v1/profiles" \
    -H "Authorization: Bearer YOUR_API_KEY"

  # SDK Installation
  npm install @palm/node    # Node.js
  pip install palm-api      # Python
  ```

  ### Enable Webhooks (Optional)
  Set up real-time updates for your integration:
  ```json
  {
    "type": "profile.updated",
    "data": {
      "profileId": "prof_123abc",
      "changes": ["compliance.status"]
    }
  }
  ```
</Steps>
